Privacy Policy

Wildlife Shorts · last updated October 23, 2026

Wildlife Shorts is a private desktop tool used only by the owner of the getpsyched! YouTube channel (channel ID UCEilpeB8mG9rGXkRTVvis2A). This policy explains what Google user data the app accesses and what it does with it. It applies to the app, not to YouTube or Google themselves.

1. Google user data the app accesses

  • Authorization: through Google OAuth 2.0 for desktop apps (local loopback redirect, PKCE), the channel owner grants https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.force-ssl. Google returns an access token and a refresh token.
  • Channel data: the ID of the authorized channel (from channels.list), used only to confirm it is the getpsyched! channel.
  • Video data: for the channel's own videos, the video ID and status fields such as privacy status and scheduled publish time (from videos.list and upload responses).

The app does not read comments, subscribers, viewers' personal data, analytics, email, contacts or any other Google account data.

2. How the data is used

  • Upload the channel's own videos (videos.insert), set their custom thumbnails (thumbnails.set), and complete or change their title, description, privacy status and publish time (videos.update).
  • Confirm that each upload and schedule really happened, and keep a local record of it.

The app never deletes videos and never acts on any channel other than getpsyched!. Google user data is not used for advertising, not sold, and not used to train machine-learning models by the app.

3. Where the data is stored

  • Refresh token and granted scopes: a local file (secrets/youtube_token.json) on the channel owner's computer. The OAuth client file (secrets/client_secret.json) is stored in the same folder. This folder is excluded from version control. The app does not add its own encryption to these files; they are protected by the computer's user account.
  • Access tokens: kept only in memory while a command runs.
  • Authorization check: a local file with the channel ID, granted scopes and the check time, with no tokens or secrets.
  • Publication logs: local files with video IDs, URLs, status, scheduled times, file hashes and API error messages. These logs are part of a local git repository on the same computer, with no remote copy.

4. Retention

The app has no automatic expiry. The token file is kept until the channel owner revokes access or deletes the file. Publication logs are kept as an append-only history until the channel owner deletes them.

5. Sharing

  • Google/YouTube: uploaded videos, thumbnails and metadata are sent to YouTube, which handles them under the YouTube Terms of Service and the Google Privacy Policy.
  • AI assistants used by the channel owner: the owner operates the project with AI assistants (Claude by Anthropic, working in the project folder, and ChatGPT by OpenAI, for coordination). They can read the project files, including the publication logs and the non-secret authorization check file (channel ID, video IDs, metadata, status). They are instructed not to open the token and client files, but that is an operating rule, not a technical barrier. Their providers process what they read under their own terms.
  • No other sharing, sale or transfer of Google user data takes place.

6. Revoking access and deleting data

  • Revoke the app's access at any time at myaccount.google.com/permissions. After that the stored refresh token stops working.
  • Delete the local token file to remove the stored authorization from the computer.
  • To ask for deletion of the local logs, write to the contact below. Videos already on YouTube are managed in YouTube Studio.

7. Google API Services User Data Policy

Wildlife Shorts' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes and contact

Changes to this policy are published on this page with a new date. Questions or requests: getpsychedmix1@gmail.com.
